
# Fluidé HRM

A Human Resource Management System built to manage employees and HR operations.

## Technology Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- Node.js
- Express
- TypeScript
- Prisma ORM

### Database
- PostgreSQL

## Features

- Authentication and role-based access control
- Employee management
- Attendance management
- Leave management
- Performance appraisals
- Celebrations and notifications
- Department collaboration
- Employee handbook
- Reports and audit logs

## Project Structure

- `frontend/` — React application
- `backend/` — API and database logic

## Local Development

1. Clone this repository.
2. Install dependencies separately in `frontend/` and `backend/`.
3. Create local `.env` files using the example environment files.
4. Configure your PostgreSQL database.
5. Run the applications using their respective development scripts.

Never commit real credentials, database passwords, or JWT secrets.
